## ❓ FAQ

**Do I need to run it as Administrator?**

Yes — admin rights are required for the overlay to attach.

**Are AI coding assistants free?**

Some tools provide free plans or limited usage. Advanced models, higher request limits, and additional agent features may require a subscription or API credits.

**Can I use AI coding assistants on Windows 11?**

Yes. Many popular coding assistants support Windows through desktop applications, browser interfaces, IDE extensions, or command-line tools.

**Which AI coding assistant is best for beginners?**

GitHub Copilot is a convenient starting point for developers who want assistance inside an existing editor. Cursor and OpenAI Codex are also worth exploring for more AI-driven workflows.

**Can AI coding assistants build complete applications?**

Some agents can create and modify multiple project files, run commands, and assist with testing. Review generated code and test the application before deployment.
